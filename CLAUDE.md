# Instructions for AI agents

Read [CONTRIBUTING.md](CONTRIBUTING.md) first. Mandatory rules:

- Commit after every meaningful unit of work, grouping only related files, so history stays traceable.
- Commit messages in **English**, Conventional Commits (`docs(adr): …`, `docs(design): …`), imperative mood, subject ≤ 72 chars, written like a professional human developer.
- **Never** add `Co-Authored-By: Claude …` or any other AI attribution trailer to commits or pull requests.
- Documents are written in Brazilian Portuguese (pt-BR) for both human and agent readers; keep the folder layout from CONTRIBUTING.md and update the indexes (`README.md`, `adr/README.md`) when adding files.
